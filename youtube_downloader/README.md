# 🐱 냥튜브 — 유튜브 다운로더

유튜브 영상 링크를 넣고 **분석 → 포맷 선택 → 다운로드** 순서로 사용하는 한국어 데스크톱 프로그램입니다. Python으로 실행하며, 고양이 테마의 화면에서 영상과 음원을 저장할 수 있습니다.

## 1. 어떤 기능이 있나요?

- 영상 제목, 재생 시간, 다운로드 가능한 포맷을 확인합니다.
- 포맷별 종류, 확장자, 해상도 또는 음원 비트레이트, 파일 크기를 표로 표시합니다.
- 원하는 저장 폴더를 선택합니다. 기본 위치는 사용자 폴더의 `Downloads`입니다.
- 다운로드 진행률, 속도, 남은 시간과 병합 상태를 표시합니다.
- 영상과 음원이 분리된 포맷은 음원을 추가로 받아 하나의 MKV 파일로 병합합니다.
- 링크 오류, 네트워크 문제, 접근 제한, 저장 문제를 한국어로 안내합니다.

## 2. 준비 사항

| 항목 | 용도 |
|---|---|
| Python 3.10 이상 | 프로그램 실행 |
| PyQt5 | 프로그램 화면 구성 |
| yt-dlp | 유튜브 정보 분석과 다운로드 |
| FFmpeg | 영상·음원 병합 및 일부 스트리밍 포맷 처리 |
| 인터넷 연결 | 영상 분석과 다운로드 |

Python 라이브러리는 `requirements.txt`로 설치합니다. 현재 파일에 지정된 버전 조건은 `PyQt5>=5.15.10,<6`, `yt-dlp>=2026.3.17`입니다.

아래 명령은 **Windows PowerShell** 기준입니다.

## 3. 설치와 실행

### 처음 실행할 때

PowerShell을 열고 다음 명령을 순서대로 실행하세요.

```powershell
# 프로젝트 폴더로 이동
cd 'C:\Users\USER\Desktop\youtube_downloader'

# Python 버전 확인
python --version

# 가상환경 생성 — 이미 .venv 폴더가 있다면 생략 가능
python -m venv .venv

# 필요한 라이브러리 설치
.\.venv\Scripts\python.exe -m pip install -r requirements.txt

# 프로그램 실행
.\.venv\Scripts\python.exe main.py
```

가상환경은 이 프로그램에서 사용할 Python과 라이브러리를 따로 보관하는 폴더입니다. 위 방식은 가상환경 활성화 명령 없이 실행할 수 있습니다.

### 다음부터 실행할 때

```powershell
cd 'C:\Users\USER\Desktop\youtube_downloader'
.\.venv\Scripts\python.exe main.py
```

현재 폴더에는 `.venv`가 있으나, 내부 라이브러리 설치 상태에 따라 설치 명령을 다시 실행해야 할 수 있습니다.

### FFmpeg 준비

**영상 전용** 포맷을 선택하면 FFmpeg가 필요합니다. 코드에서는 `m3u8` 프로토콜 또는 확장자도 FFmpeg 필요 대상으로 확인합니다. 그 밖의 포맷도 yt-dlp 처리 과정에서 추가 도구가 필요할 수 있습니다.

FFmpeg를 설치하고 `ffmpeg.exe`가 들어 있는 폴더를 Windows의 사용자 `PATH`에 등록하세요. 배포 파일 안내는 [FFmpeg 다운로드 페이지](https://ffmpeg.org/download.html)를 참고할 수 있습니다.

설정 후 PowerShell과 앱을 다시 열고 확인합니다.

```powershell
ffmpeg -version
```

버전 정보가 출력되면 터미널에서 FFmpeg를 찾을 수 있는 상태입니다. 앱 역시 `PATH`에서 FFmpeg를 찾습니다.

## 4. 사용 방법

1. 프로그램을 실행합니다.
2. **유튜브 영상 링크** 입력란에 영상 주소를 붙여 넣습니다.
3. **📁 폴더 선택**을 눌러 저장할 폴더를 고릅니다.
4. **😺 영상 분석하기**를 누릅니다.
5. 제목과 길이를 확인하고, 포맷 표에서 원하는 행을 클릭합니다.
6. **🐾 내 폴더에 다운로드**를 누릅니다.
7. **다운로드 및 후처리 완료!** 메시지가 나오면 선택한 폴더에서 파일을 확인합니다.

링크를 바꾸면 기존 분석 결과가 초기화되므로 다시 분석해야 합니다. 분석이나 다운로드 중에는 입력과 선택 버튼이 잠기며, 작업이 끝난 뒤 앱을 종료할 수 있습니다. 별도의 작업 취소 버튼은 없습니다.

### 입력 가능한 주소

영상 ID가 있는 다음 형태를 지원합니다.

```text
https://www.youtube.com/watch?v=영상ID
https://youtu.be/영상ID
https://www.youtube.com/shorts/영상ID
https://www.youtube.com/live/영상ID
https://www.youtube.com/embed/영상ID
```

`영상ID`는 실제 11자리 영상 식별자로 바꾸세요. 모바일 및 YouTube Music 도메인의 영상 주소도 코드에서 허용합니다. 영상 주소에 재생목록 정보가 붙어 있으면 이를 제거하고 해당 영상 하나만 처리합니다.

## 5. 포맷은 어떻게 고르나요?

| 표의 종류 | 실제 저장 방식 | 알아둘 점 |
|---|---|---|
| 영상+음원 | 선택한 포맷으로 다운로드 | 영상과 소리가 함께 들어 있는 포맷 |
| 영상 전용 | 선택한 영상 + yt-dlp가 고르는 최적 음원을 MKV로 병합 | FFmpeg 필요. 표의 확장자와 최종 확장자가 다를 수 있음 |
| 음원 전용 | 선택한 음원의 원래 포맷으로 다운로드 | MP3 변환 기능은 없음 |

영상 전용의 병합은 영상과 음원을 하나의 파일에 담는 과정이며, 코드에는 화질이나 음질을 바꾸는 재인코딩 옵션이 없습니다. 제공되는 해상도와 확장자는 영상마다 다릅니다.

### 표의 파일 크기와 진행률

- **정확:** 원본 정보에 파일 크기가 있는 경우입니다.
- **예상:** 원본 정보에 추정 크기만 있는 경우입니다.
- **알 수 없음:** 크기 정보가 없는 경우입니다.
- 영상 전용 행의 크기는 선택한 영상 스트림 기준입니다. 추가 음원까지 포함한 최종 MKV 크기와는 다릅니다.
- 진행률은 현재 받는 파일 기준입니다. 영상 다음에 음원을 받을 때 진행률이 다시 시작할 수 있습니다.
- 전체 크기를 모르거나 병합 중이면 진행 막대가 계속 움직이는 형태로 표시됩니다.

## 6. 저장 파일

파일명은 다음 형식을 사용합니다.

```text
영상 제목 [영상ID].확장자
```

Windows에서 사용할 수 없는 파일명 문자를 처리하며, 제목 부분은 길이를 제한합니다. 영상 전용을 선택해 병합한 결과는 `.mkv`로 저장합니다.

기존 파일 처리와 이어받기는 yt-dlp 기본 동작을 따릅니다. 다운로드 실패 시 임시 `.part` 파일 등이 남을 수 있습니다.

## 7. 문제가 생겼을 때

| 증상 | 확인할 내용 |
|---|---|
| `python` 명령을 찾을 수 없음 | Python 설치와 PATH 등록 여부를 확인하고 PowerShell을 다시 여세요. |
| `No module named ...` 오류 | 위의 `pip install -r requirements.txt` 명령을 가상환경 Python으로 실행하세요. |
| 올바른 링크를 입력하라는 안내 | 채널이나 재생목록 주소 대신 영상의 공유 링크를 입력하세요. |
| FFmpeg가 필요하다는 안내 | FFmpeg 설치와 PATH를 확인하고 앱을 다시 실행하세요. |
| 분석 또는 다운로드 실패 | 인터넷 연결과 영상 접근 가능 여부를 확인하세요. YouTube 변경이 원인일 수 있으므로 yt-dlp 업데이트도 시도할 수 있습니다. |
| 저장 관련 오류 | 선택한 폴더가 존재하는지, 쓰기 권한과 디스크 여유 공간이 있는지 확인하세요. |
| 다운로드 버튼이 비활성화됨 | 영상 분석이 끝난 뒤 포맷 표에서 한 행을 선택하세요. |

yt-dlp 업데이트 명령:

```powershell
cd 'C:\Users\USER\Desktop\youtube_downloader'
.\.venv\Scripts\python.exe -m pip install --upgrade yt-dlp
```

## 8. 지원 범위와 제한

- 한 번에 영상 하나만 처리합니다. 재생목록 일괄 다운로드는 지원하지 않습니다.
- 진행 중인 실시간 방송은 거부합니다. 방송 종료 후 다시 시도하세요.
- DRM이 표시된 포맷은 목록에서 제외합니다.
- 로그인·쿠키 입력, 접근 제한 우회, MP3 변환 기능은 구현되어 있지 않습니다.
- 비공개·회원 전용·연령 제한 등 인증이 필요한 영상은 실패할 수 있습니다.
- 다운로드 가능 여부는 YouTube의 포맷 제공과 접근 조건, yt-dlp 호환 상태에 따라 달라집니다.

## 9. 폴더와 코드 구성

| 파일 / 폴더 | 설명 |
|---|---|
| `main.py` | 화면 구성, 링크 검사, 영상 분석, 다운로드 및 오류 처리 코드 |
| `requirements.txt` | 설치할 Python 라이브러리와 버전 조건 |
| `README.md` | 설치 및 사용 안내 — 이 문서 |
| `.gitignore` | 가상환경과 Python 임시 파일 등을 Git 추적에서 제외 |
| `.venv/` | 로컬 Python 가상환경 |
| `__pycache__/` | Python이 생성하는 캐시 |
| `.test-deps/` | 로컬 보조 폴더. 실행 코드에서 참조하지 않으며 내부 용도는 이 문서에서 확인하지 않음 |

`main.py`의 주요 구성은 다음과 같습니다.

| 구성 | 역할 |
|---|---|
| `single_video_url()` | 유튜브 주소를 검사하고 단일 영상 주소로 정리 |
| `human_size()`, `duration_text()` | 용량과 시간을 읽기 쉬운 문자열로 표시 |
| `format_kind()` | 포맷을 영상+음원, 영상 전용, 음원 전용으로 분류 |
| `friendly_error()` | 오류를 한국어 안내로 변환 |
| `Worker` | 별도 스레드에서 yt-dlp 분석과 다운로드 실행, 진행 상태 전달 |
| `MainWindow` | 입력란, 포맷 표, 버튼, 진행 표시와 창 종료 처리 |

이 문서는 `main.py`와 설정 파일을 읽어 작성했습니다. 실제 유튜브 다운로드 성공 여부를 검증한 문서는 아닙니다.
